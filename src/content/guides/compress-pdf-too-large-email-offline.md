> **읽기 전 참고** — Apple과 Adobe의 공식 도움말을 참고해 작성했습니다. 실제 파일로 압축률을 측정하거나 모든 버전의 메뉴를 직접 시험한 것은 아닙니다. 제품 버전과 라이선스에 따라 메뉴 이름이 다를 수 있으므로 사용 중인 제품의 표시를 확인하세요.

## PDF 용량 줄이기: 온라인 업로드 없이 해결하는 방법

이메일에 PDF를 첨부하려는데 용량 제한 때문에 전송이 되지 않는다면, **파일이 얼마나 큰지**, **어떤 종류의 PDF인지**, **수신자가 꼭 보존해야 하는 기능이 무엇인지**부터 확인하세요.

- **Mac 사용자**라면 기본 설치된 **미리보기** 앱에서 **파일 → 내보내기 → Quartz 필터 → 파일 크기 줄이기** 기능을 사용해 새로운 파일을 만들 수 있습니다.
- **Windows 또는 Mac에서 Adobe Acrobat 데스크톱을 사용한다면**, 제품에 해당 기능이 제공되는 경우 **크기가 축소된 PDF**로 별도 저장할 수 있습니다.
- **Windows에 기본으로 설치된 PDF 보기 기능만 있다면**, 모든 PDF에 적용되는 범용 압축 버튼이 있다고 단정할 수 없습니다. 원본 Word·PowerPoint에서 다시 PDF로 내보내거나, 사용이 승인된 로컬 PDF 도구를 검토하는 편이 안전합니다.

원본 PDF를 덮어쓰지 말고 복사본을 만들며, 압축 후에는 **용량뿐 아니라 글자·이미지·링크·양식·전자서명**까지 검사하세요. 파일이 작아졌다고 무조건 전송 가능한 정상 문서가 되는 것은 아닙니다.

## 어떤 PDF인지 먼저 확인해야 하는 이유

파일 내부 구성이 다르면 압축 효과도 달라집니다.

| 원본 PDF 유형 | 크기를 줄일 가능성이 있는 요소 | 중요한 위험 |
| --- | --- | --- |
| 종이 문서 스캔본 | 이미지 해상도와 압축률 | 작은 글씨, 도장, 서명이 흐려질 수 있음 |
| 사진 많은 발표 자료 | 고해상도 사진 데이터 | 그래프의 범례나 그림이 손상될 수 있음 |
| 텍스트 위주 PDF | 불필요한 데이터나 글꼴 정보 | 이미 최적화됐으면 감소 폭이 작음 |
| 입력 가능한 PDF 양식 | 일부 부가 요소 | 입력 필드·계산·제출 기능이 변경될 수 있음 |
| 전자서명된 문서 | 수정하지 않는 것이 우선 | 서명 유효성에 문제가 생길 수 있음 |
| 접근성을 고려한 문서 | 이미지 및 기타 리소스 | 텍스트 선택, 태그, 읽기 순서가 달라질 수 있음 |

이메일이나 제출 사이트가 제한하는 **파일당 용량**도 확인해야 합니다. 예를 들어 제출 한도가 10MB라면 파일을 정확히 10MB에 맞추기보다 약간 여유를 두는 편이 낫습니다. 이메일 서비스의 인코딩·전송 규칙에 따라 실제 첨부 한도가 다를 수 있으므로 하나의 수치를 모든 서비스에 적용하지 마세요.

## 1. Mac 미리보기에서 PDF 크기 줄이기

Mac 사용자는 별도 웹사이트에 파일을 업로드하지 않고 **미리보기(Preview)** 앱에서 PDF를 내보낼 수 있습니다. Apple의 공식 안내에 따른 순서는 다음과 같습니다.

1. Mac의 **미리보기** 앱으로 PDF를 엽니다.
2. 상단 메뉴에서 **파일 → 내보내기**를 선택합니다.
3. **Quartz 필터** 팝업 메뉴에서 **파일 크기 줄이기**를 선택합니다.
4. 기존 파일과 구분되는 새 이름과 저장 위치를 지정합니다.
5. **저장**을 선택합니다.
6. 내보낸 PDF를 다시 열어 크기와 품질을 비교합니다.

가급적 원본과 새 파일을 나란히 띄워 **가장 작은 글씨, 표의 숫자, 도장, QR 코드, 이미지의 가는 선**을 확인하세요.

Apple은 압축하면 원래 PDF보다 품질이 떨어질 수 있으며 파일 크기와 화질은 선택한 옵션에 따라 달라진다고 명시합니다. 따라서 **원본이 20MB이면 반드시 5MB가 된다**처럼 압축률을 보장할 수 없습니다.

### Mac에서 저장할 때 원본을 보존하는 방법

미리보기에서 기존 파일을 대치할지 묻는다면 새 이름으로 내보내는 쪽을 선택하세요. 예를 들어 원본이 제출서류.pdf라면 제출서류\_메일용.pdf처럼 구분합니다.

압축한 PDF가 읽기 어려워졌을 때는 이미 품질이 낮아진 압축본을 다시 압축하지 말고 **원본에서 다른 옵션으로 다시 시작**하세요. 반복 재압축으로 이미지가 더 흐려질 수 있습니다.

### 선형화된 PDF와 파일 크기 줄이기는 다릅니다

미리보기에서는 지원되는 macOS 버전에 따라 **선형화된 PDF 생성**, **화면에 맞게 이미지 최적화**, **JPEG로 이미지 저장** 등의 옵션이 제공될 수 있습니다.

- **선형화된 PDF 생성:** 브라우저에서 문서를 더 빠르게 열 수 있도록 하는 목적입니다. 항상 파일이 더 작아지는 기능은 아닙니다.
- **화면에 맞게 이미지 최적화:** 화면 표시를 기준으로 이미지 데이터를 조정할 수 있습니다.
- **JPEG로 이미지 저장:** 이미지 압축 방식이 바뀌어 화질에 영향을 줄 수 있습니다.

이 옵션들은 서로 목적이 다르므로 전부 한 번에 적용하기보다 **한 번에 하나씩 선택해 결과를 비교**하는 편이 좋습니다.

## 2. Adobe Acrobat 데스크톱에서 압축하기

Adobe는 데스크톱용 Acrobat에서 PDF 크기를 줄이는 기능을 문서화하고 있습니다. 구독·제품 종류 및 설치 버전에 따라 해당 기능의 사용 가능 여부는 달라질 수 있으므로 **무료 Acrobat Reader만 설치된 PC에서도 반드시 된다**고 가정하면 안 됩니다.

### Windows에서 실행

1. 압축할 PDF를 데스크톱 **Adobe Acrobat**에서 엽니다.
2. **메뉴 → 다른 이름으로 저장 → 크기가 축소된 PDF**를 선택합니다.
3. 호환성 설정에서 문서를 받는 사람이 사용하는 Acrobat 버전을 고려해 선택합니다.
4. **확인**을 누릅니다.
5. 새 파일 이름과 저장 위치를 지정해 저장합니다.

### Mac에서 실행

1. PDF를 데스크톱 Adobe Acrobat에서 엽니다.
2. **파일 → 다른 이름으로 저장 → 크기가 축소된 PDF**를 선택합니다.
3. 호환성 설정을 확인합니다.
4. **확인**을 누른 뒤 새 이름으로 저장합니다.

Adobe 공식 도움말은 여러 파일에 같은 축소 설정을 적용하는 방법도 설명합니다. 다만 업무 문서를 일괄 압축했다면 **압축이 성공했다는 표시만 믿지 말고 샘플 파일의 실제 내용을 확인**해야 합니다.

### Acrobat Pro의 고급 최적화는 언제 필요한가요?

고급 기능이 제공되는 환경에서는 **최적화된 PDF**에서 이미지, 글꼴, 투명도, 불필요한 개체 등을 세부 조정할 수 있습니다.

| 조정 대상 | 용량 감소 원리 | 주의할 점 |
| --- | --- | --- |
| 이미지 | 해상도 낮추기·압축 | 스캔 문자의 가독성 저하 |
| 글꼴 | 포함 정보 축소 | 다른 PC에서 글꼴이 대체될 위험 |
| 투명도 | 효과 단순화 | 디자인이 달라질 위험 |
| 양식·개체 | 부가 데이터 제거 | 인터랙티브 양식 기능 변화 |
| 사용자 데이터 | 주석 등 일부 데이터 제거 | 필요한 검토 이력까지 제거될 수 있음 |

특히 **한국어 글꼴을 포함 해제하면** 수신자의 컴퓨터에서 다른 글꼴이 표시되거나 줄바꿈이 달라질 수 있습니다. 문서의 원래 모양이 중요한 계약서·인증 문서는 글꼴 최적화보다 **가독성 보존**을 우선하세요.

## 3. Windows에 Acrobat 압축 기능이 없다면

Windows 기본 PDF 보기·인쇄 기능을 **전용 PDF 최적화 도구와 동일하게 생각하면 안 됩니다.** PDF를 다시 인쇄하거나 다른 이름으로 저장하는 방법이 어떤 파일에서는 용량을 줄이더라도, 모든 파일에서 효과가 있다고 보장되지 않습니다.

우선 다음 순서로 확인하세요.

1. **원본 Word, PowerPoint 또는 스캔 이미지**가 남아 있는지 확인합니다.
2. 원본 편집 파일이 있다면 **원본에서 PDF로 다시 내보내기**를 시도합니다. 프로그램에서 제공하는 품질·이미지 설정을 확인하되 글자가 흐려지지 않는지 비교합니다.
3. 회사 또는 기관이 승인한 **로컬 설치형 PDF 편집 도구**가 있다면 해당 프로그램의 공식 안내에 따라 압축합니다.
4. 별도의 도구가 없고 문서가 기밀이라면 임의의 온라인 업로드 서비스보다 **제출처의 보안 파일 전송 방법**을 먼저 문의합니다.

**PDF를 ZIP으로 압축**하는 방법도 있지만, PDF 내부 이미지와 데이터가 이미 압축되어 있으면 용량 감소가 작을 수 있습니다. 또한 제출 사이트가 ZIP 파일을 허용하지 않을 수도 있습니다.

## 4. 스캔 PDF는 왜 화질 손상이 더 클까요?

스캐너로 받은 PDF는 각 페이지가 이미지일 수 있습니다. 이때 파일 크기를 크게 줄이는 가장 쉬운 방법은 이미지 해상도나 압축률을 조정하는 것이지만, **작은 글자·주민등록번호·계약 조건·스탬프**가 흐려질 위험도 커집니다.

품질을 확인할 때는 페이지 전체만 보지 말고 다음 부분을 확대하세요.

- 가장 작은 글꼴로 적힌 숫자와 날짜
- 도장과 서명이 찍힌 부분
- 표의 회색 음영, 점선, 가는 테두리
- QR 코드와 바코드
- 첨부 이미지의 중요한 글자

문서에서 **텍스트를 검색하거나 선택할 수 있는지**도 확인합니다. 원래 이미지로만 이루어진 PDF였다면 압축한다고 자동으로 OCR(문자 인식)이 추가되는 것은 아닙니다. 수신기관이 검색 가능한 PDF를 요구한다면 OCR은 별도 작업입니다.

## 5. 전자서명과 입력 가능한 양식은 별도 주의

PDF 안에 **디지털 서명**이 들어 있거나 온라인 신청용 입력 필드가 포함된 경우에는 단순히 압축 전후 크기만 비교해서는 안 됩니다.

- **전자서명 문서:** 파일 내용을 다시 저장하거나 변환하면 서명 유효성 검증에 영향을 줄 수 있습니다. 서명된 원본은 수정하지 말고 제출기관에서 압축본을 허용하는지 문의하세요.
- **입력 가능한 양식:** 변환 뒤 필드를 클릭하고 값을 입력할 수 있는지 확인합니다. 계산·제출 버튼이 있다면 해당 동작도 점검해야 합니다.
- **책갈피·하이퍼링크:** 목차에서 필요한 페이지로 이동하는지, 링크가 보존됐는지 확인합니다.
- **접근성이 필요한 문서:** 텍스트 선택, 읽기 순서, 스크린리더 호환성 등을 확인합니다.

특히 공공기관과 계약 상대방이 **원본 서명 파일 자체**를 요구하는 경우에는 크기를 줄이려고 파일을 변경하는 대신 다른 제출 방식을 요청하는 것이 안전합니다.

## 6. 압축 후 품질을 확인하는 체크리스트

파일을 전송하기 전에 원본과 압축본을 나란히 놓고 비교하세요.

| 검수 항목 | 확인 방법 | 통과 기준 |
| --- | --- | --- |
| 실제 용량 | 파일 정보에서 바이트 또는 MB 비교 | 제출처 제한보다 충분히 작음 |
| 페이지 | 첫 장·마지막 장·전체 장수 확인 | 누락·순서 변경 없음 |
| 글자 | 작은 글씨를 확대해 읽기 | 숫자·기호를 구분할 수 있음 |
| 사진·도표 | 중요 이미지와 가는 선 비교 | 중요한 정보가 남아 있음 |
| 한글 폰트 | 다른 PDF 뷰어에서도 열어보기 | 글꼴 대체로 내용이 달라지지 않음 |
| 텍스트 검색 | 핵심 문구 검색·선택 | 수신 목적에 필요한 검색 기능 유지 |
| 링크·책갈피 | 클릭해 이동 | 필요한 기능 작동 |
| 입력 양식 | 필드 클릭·입력 | 원본 기능 유지 |
| 서명 | 서명 상태 확인 | 필요한 유효성 유지 |
| 개인정보 | 별도 교정·정리 필요 여부 확인 | 허용된 정보만 포함 |

예를 들어 제출 한도가 **10MB**이고 원본이 **18MB**라면 목표는 단순히 10MB 미만으로 만드는 것에 그치지 않습니다. 중요 숫자가 흐려지지 않고, 제출처가 요구하는 기능이 정상적으로 유지되는지도 확인해야 합니다. 이는 **계산 예시**이지 특정 PDF에서 측정한 압축 결과는 아닙니다.

## 7. 용량 줄이기와 개인정보 제거는 완전히 다른 일

**PDF 압축은 개인정보 삭제 기능이 아닙니다.** 파일을 압축해도 이름, 연락처, 숨겨진 메타데이터, 주석, 첨부파일 등이 남을 수 있습니다.

Adobe는 민감한 정보를 보호하기 위해 **교정(Redaction)**과 **숨겨진 정보 정리(Sanitization)**를 서로 다른 과정으로 설명합니다.

- **교정:** 보이는 텍스트·이미지 중 공개하면 안 되는 내용을 영구적으로 제거합니다.
- **숨겨진 정보 정리:** 메타데이터, 포함된 개체, 스크립트 등 보이지 않는 정보를 별도로 제거합니다.

문서에 흰색 사각형을 덮거나 페이지를 잘라낸 뒤 저장하는 방식만으로 민감한 원문이 완전히 제거된다고 믿어서는 안 됩니다. 개인정보를 지워야 하는 경우에는 **전용 교정 기능을 정확히 사용하고 결과물을 별도로 검증**하세요.

주민등록증, 금융자료, 인사자료, 계약서, 의료 정보처럼 민감한 문서를 **출처를 확인할 수 없는 무료 PDF 웹사이트에 업로드하는 행위**는 피하는 것이 좋습니다. 파일 저장·재처리·삭제 정책을 확인할 수 없기 때문입니다.

## 8. 파일이 여전히 너무 크다면

이미 압축했는데도 수신처 한도를 넘는다면 다음 대안을 검토하세요.

- **원본 편집 파일로 다시 시작:** 반복 압축된 PDF를 다시 줄이기보다 원본 Word·이미지에서 적절한 설정으로 새 PDF 생성
- **승인된 보안 전송 서비스 이용:** 회사나 제출기관이 제공하는 보안 업로드 경로 확인
- **파일 분할 허용 여부 확인:** 접수처가 여러 개 파일 제출을 허용하는 경우에만 분할
- **스캔 원본 재생성:** 출력 목적을 충족하는 범위에서 원본 스캔 설정 재검토
- **제출 한도 문의:** 지정된 크기 이상을 허용할 수 있는 공식 절차가 있는지 확인

공문서나 서명 파일을 **임의로 여러 개로 나눠 제출하지 마세요.** 기관이 단일 원본 파일을 요구하는 경우에는 원래 문서의 완전성이 더 중요합니다.

## 흔히 시도하지만 추천하기 어려운 방법

| 방법 | 문제점 |
| --- | --- |
| 확장자나 파일 이름만 변경 | 실제 파일 용량은 줄지 않음 |
| PDF를 ZIP으로 감싸기 | 효과가 작을 수 있고 업로드 형식 제한 가능 |
| PDF를 다시 PDF로 인쇄 | 입력 양식·링크·접근성·레이아웃 변경 가능 |
| 이미지 품질을 극단적으로 낮춤 | 작은 문자와 QR 코드 훼손 |
| 처음 보는 무료 웹사이트에 올림 | 개인정보·보관 기간·삭제 정책 확인 어려움 |
| 같은 압축본을 여러 차례 재압축 | 품질만 나빠지고 용량은 거의 안 줄 수 있음 |

핵심은 **가장 많이 압축하는 것**이 아니라 **받는 사람이 필요한 내용을 문제없이 사용할 수 있는 크기까지 줄이는 것**입니다.

## 이메일로 보내기 전 최종 체크리스트

- [ ] 제출처의 실제 첨부 제한을 확인했다.
- [ ] 원본 PDF를 별도로 보관했다.
- [ ] 새 파일 이름과 저장 위치를 구분했다.
- [ ] 작은 글씨·표·도장·이미지를 열어 확인했다.
- [ ] 페이지 수와 순서가 그대로다.
- [ ] 검색 가능한 텍스트·책갈피·링크가 필요하다면 보존됐다.
- [ ] 전자서명과 입력 가능한 필드에 문제가 없다.
- [ ] 개인정보를 삭제해야 한다면 별도 교정·정리 절차를 진행했다.
- [ ] 파일을 열 수 있는지 실제 수신 환경에 가까운 프로그램에서 확인했다.
- [ ] 기관·회사 보안 정책에 어긋나는 외부 업로드를 하지 않았다.

## 자주 묻는 질문

### PDF를 무료로, 온라인 업로드 없이 줄일 수 있나요?

Mac에서는 기본 미리보기 앱의 Quartz 필터를 사용할 수 있습니다. Windows에서는 설치된 프로그램에 따라 방법이 다르므로 모든 PC에 무료 기본 압축 기능이 있다고 단정할 수는 없습니다.

### PDF를 압축하면 글씨가 흐려지나요?

그럴 수 있습니다. 특히 스캔 페이지나 이미지로 저장된 글자는 해상도와 압축률에 영향을 받습니다. 원본을 보관하고 작은 글씨를 확대해 검수해야 합니다.

### 메일로 보내려면 PDF는 몇 MB 이하여야 하나요?

서비스와 수신 서버마다 제한이 다릅니다. 정확한 제한을 확인하고 여유를 두세요. 모든 이메일 서비스에 동일한 제한을 적용할 수는 없습니다.

### Mac 미리보기의 선형화된 PDF를 사용하면 용량이 무조건 줄어드나요?

그렇지 않습니다. 선형화는 웹브라우저에서 파일이 열리는 방식을 최적화하는 목적이며, 파일 크기 감소를 보장하는 기능과 다릅니다.

### PDF를 압축하면 주민등록번호·숨겨진 정보도 삭제되나요?

아닙니다. 압축과 개인정보 제거는 별개입니다. Adobe가 안내하는 교정·숨겨진 정보 정리처럼 적절한 도구와 검증이 필요합니다.

### 압축한 PDF의 전자서명이 무효가 될 수 있나요?

서명된 문서의 내용을 다시 저장하거나 재구성하면 유효성에 영향을 줄 수 있습니다. 서명 원본은 보존하고 제출처가 수정된 파일을 허용하는지 먼저 확인하세요.
